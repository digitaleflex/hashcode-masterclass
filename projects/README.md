# Projets pratiques — HashCode Academy

Les projets prolongent les cours en imposant des critères d'acceptation vérifiables. Un projet doit avoir un périmètre réaliste, un starter distinct de la solution, des tests ou une méthode de vérification, un barème et une revue des risques.

## Règles
- Les projets de sécurité se font exclusivement sur des environnements locaux autorisés.
- Ne pas stocker de secrets ou de données réelles.
- Une solution de référence est un exemple, pas nécessairement l'unique solution acceptable.
- Une fonctionnalité n'est considérée comme terminée que si ses critères sont démontrés.
