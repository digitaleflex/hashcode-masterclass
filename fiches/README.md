## Comment utiliser ces fiches
1. Lire la fiche avant l’exercice associé.
2. Reproduire les exemples dans un environnement d’exécution.
3. Masquer la correction ou prédire la sortie avant d’exécuter.
4. Modifier une valeur pour vérifier sa compréhension.
5. Expliquer la notion avec ses propres mots.

Les exemples sont des supports pédagogiques. Exécute-les dans l’environnement indiqué et adapte les commandes au projet utilisé.
