# Politique de sécurité

## Périmètre
Ce dépôt contient principalement des supports, exemples et exercices locaux. Il n'est pas une plateforme de production ni un moteur d'exécution de code apprenant.

## Signaler une vulnérabilité
Ne publiez pas de secrets, données personnelles ou détails exploitables dans une issue publique. Contactez le mainteneur via les coordonnées privées disponibles sur GitHub avec une description minimale, l'impact et des étapes de reproduction sûres.

## Règles de contribution
- Utiliser uniquement des systèmes de laboratoire ou des cibles explicitement autorisées.
- Ne jamais committer jetons, mots de passe, clés privées ou données de clients.
- Les démonstrations doivent être locales, contrôlées et accompagnées d'une correction.
- Ne pas ajouter de charge destructive, exfiltration ou persistance malveillante.
- Préférer des dépendances minimales.
- Ne jamais exécuter du code arbitraire soumis par un utilisateur dans un processus privilégié.

Ce document ne signifie pas qu'un SLA ou une équipe de sécurité dédiée sont en place.
