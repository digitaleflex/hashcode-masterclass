07 / PREMIER PROGRAMME

Écrire. Exécuter. Observer.

Une fonction reçoit une donnée, effectue un travail et renvoie une valeur.

À retenir

  • const déclare une liaison non réassignable.
  • return renvoie un résultat.
  • console.log() affiche une valeur.
const name = "HashCode";

function greet(person) {
  return `Bienvenue chez ${person} !`;
}

console.log(greet(name));

// Sortie :
// Bienvenue chez HashCode !

Exécution dans un fichier hello.js : node hello.js

09 / STRUCTURES DE DONNÉES

Tableaux + objets

Un tableau peut contenir plusieurs objets qui décrivent chacun une tâche.

Filtrer une collection

filter() renvoie un nouveau tableau contenant les éléments qui respectent la condition.

const tasks = [
  { id: 1, title: "Apprendre JS", completed: false },
  { id: 2, title: "Découvrir TS", completed: true },
];

const completed = tasks.filter(
  task => task.completed
);

console.log(completed);

10 / MINI-DÉFI · 5 MIN

Calculez le total

Sans calculatrice : quelle expression permet d'additionner tous les prix du tableau ?

const prices = [1000, 2500, 1500];

// TODO : calculer et afficher la somme.

Indice

Un accumulateur mémorise le total courant à chaque étape.

Correction

const total = prices.reduce(
  (sum, price) => sum + price, 0
);
console.log(total); // 5000

11 / POURQUOI TYPESCRIPT ?

Rendre les attentes explicites

JAVASCRIPT

Conversion implicite possible

function total(price, qty) {
  return price * qty;
}

total("1500", 3); // 4500

La chaîne peut être convertie implicitement en nombre.

TYPESCRIPT

Signaler une incohérence

function total(
  price: number,
  qty: number
): number {
  return price * qty;
}

total("1500", 3); // erreur de type

Le contrôle statique aide à repérer le problème avant exécution.

Les types n'éliminent pas tous les bugs et ne remplacent pas la validation des données à l'exécution.

12 / TYPOLOGIE DES FONCTIONS

Définir un contrat de fonction

Paramètres typés

Ils documentent quelles valeurs la fonction attend.

Retour typé

Il indique la nature de la valeur que la fonction doit renvoyer.

Vérification statique

Le compilateur signale certaines incohérences avant l'exécution.

function calculateTotal(
  price: number,
  quantity: number
): number {
  return price * quantity;
}

calculateTotal(1500, 3);

// Erreur de type :
calculateTotal("1500", 3);

13 / MODÉLISER LES DONNÉES

Une tâche, un contrat

Une interface décrit les propriétés attendues. Elle rend les données plus prévisibles à manipuler.

Pourquoi c'est utile ?

  • Propriétés explicites.
  • Autocomplétion dans l'éditeur.
  • Détection plus précoce des erreurs de structure.
interface Task {
  id: number;
  title: string;
  completed: boolean;
}

const task: Task = {
  id: 1,
  title: "Mon premier projet",
  completed: false
};
