Il fournit un environnement pour exécuter JavaScript côté client.

JAVASCRIPT — LES FONDAMENTAUX / APPRENDRE PAR LA PRATIQUE

Les types primitifs à reconnaître

Le type influence les opérations possibles sur une valeur.

  • string : texte — « HashCode ».
  • number : entiers et décimaux — 42, 3.14.
  • boolean : true ou false.
  • null : absence volontaire de valeur.
  • undefined : aucune valeur assignée.
  • object : objets et tableaux.
  • symbol et bigint : cas plus rares, à connaître de nom.
typeof "HashCode"; // "string"
typeof 42;         // "number"
typeof true;       // "boolean"
typeof undefined;  // "undefined"
typeof null;       // "object" (particularité historique)

function ou fonction fléchée ?

Les deux formes sont utiles ; choisissez la plus lisible.

A

TYPESCRIPT — LES FONDAMENTAUX / APPRENDRE PAR LA PRATIQUE

Le problème que TypeScript aide à résoudre

Une erreur peut venir d’une valeur qui n’a pas la forme attendue.

function double(value) {
  return value * 2;
}

double("bonjour");
À RETENIR

La fonction attend-elle un nombre, une chaîne ou les deux ? Le code ne le dit pas.

RÉSULTAT ATTENDU
NaN — aucune erreur levée : le résultat est silencieusement faux.
TYPESCRIPT — LES FONDAMENTAUX / APPRENDRE PAR LA PRATIQUE

Rendre le contrat explicite

TypeScript permet d’indiquer les types attendus.

A

JavaScript

  • function double(value) {
  • return value * 2;
  • }
  • Le contrat n’est pas déclaré.
B

TypeScript

  • function double(value: number): number {
  • return value * 2;
  • }
  • L’éditeur et le compilateur peuvent signaler un argument incompatible.
TYPESCRIPT — LES FONDAMENTAUX / APPRENDRE PAR LA PRATIQUE

Le typage est vérifié avant l’exécution

Les annotations TypeScript ne sont pas des contrôles automatiques à l’exécution.

  • Le compilateur analyse les types statiquement.
  • Le JavaScript émis ne conserve généralement pas les annotations.
  • Une donnée reçue d’une API doit être validée à l’exécution.
  • Le typage réduit certaines erreurs ; il ne supprime pas tous les bugs.

function addTask(title: string): Task {
  const cleanTitle = title.trim();
  if (!cleanTitle) {
    throw new Error("Le titre est obligatoire");
  }
  const task: Task = {
    id: nextId++,
    title: cleanTitle,
    status: "todo",
  };
  tasks.push(task);
  return task;
}

Afficher les tâches

Séparer la représentation des données de leur affichage.

function listTasks(): void {
  if (tasks.length === 0) {
    console.log("Aucune tâche.");
    return;
  }
  for (const task of tasks) {
    const mark = task.status === "done" ? "✓" : "○";
    console.log(`${mark} ${task.id}. ${task.title}`);
  }
}

Terminer une tâche

Rechercher par identifiant, puis modifier son état.

function completeTask(id: number): boolean {
  const task = tasks.find(item => item.id === id);
  if (!task) return false;
  task.status = "done";
  return true;
}

Défi : supprimer une tâche

Une recherche renvoie un index ou -1.

function removeTask(id: number): boolean {
  const index = tasks.findIndex(task => task.id === id);
  if (index === -1) return false;
  tasks.splice(index, 1);
  return true;
}
  • findIndex retourne -1 si rien ne correspond.
  • splice modifie le tableau en place.
  • Le booléen permet à l’appelant de réagir.
