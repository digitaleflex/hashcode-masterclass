# Index pédagogique — HashCode Masterclass JavaScript & TypeScript

**HashCode Academy · LEARN · BUILD · BELONG**

Cet index rassemble les 40 fiches de référence du parcours. Il est conçu pour la lecture sur GitHub, le téléchargement du dépôt et l'utilisation hors ligne.

## Comment utiliser les fiches

- **RES — Fiches de résumé :** comprendre une notion, suivre des exemples, faire les exercices et vérifier les corrigés.
- **CS — Cheat sheets :** retrouver rapidement une syntaxe ou une règle pendant un exercice ou un projet.
- **Ordre recommandé :** suivre les RES de 01 à 20. Les CS servent de référence en parallèle, pas de remplacement au cours.
- **Méthode d'apprentissage :** lire l'objectif, prédire le résultat avant d'exécuter le code, refaire l'exemple sans copier, puis résoudre les exercices sans regarder le corrigé.

## Jalons de progression

- [ ] Je peux expliquer les concepts sans réciter la fiche.
- [ ] Je peux refaire les exemples de mémoire et expliquer les sorties.
- [ ] Je sais diagnostiquer une erreur à partir de son message.
- [ ] Je peux écrire une petite fonctionnalité sans copier la correction.
- [ ] Je peux tester les cas normaux, limites et erreurs.
- [ ] Je peux expliquer les choix de sécurité et les limites du typage.
- [ ] Je peux livrer le projet final avec un README clair.

## Qualité et maintenance

Les fiches évoluent avec le parcours. Avant une nouvelle session, vérifier les liens, les exemples exécutables, les versions des outils et l'alignement avec le contenu réellement enseigné. Les fiches avancées ne doivent pas être présentées comme des prérequis pour les premiers exercices.

Voir aussi : [Rapport d'audit pédagogique et technique](AUDIT-PEDAGOGIQUE-TECHNIQUE.md).
