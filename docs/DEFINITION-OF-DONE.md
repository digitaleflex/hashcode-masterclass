# Definition of Done — ressources pédagogiques

Une ressource n'est prête à être diffusée que si les critères applicables ci-dessous sont satisfaits.

## Pour toute ressource
- [ ] Objectif et public visé clairement indiqués.
- [ ] Langue, niveau et prérequis cohérents avec le parcours.
- [ ] Termes techniques définis et utilisés de façon cohérente.
- [ ] Liens locaux vérifiés et liens externes justifiés.
- [ ] Accessibilité de base contrôlée : structure, titres, liens explicites, clavier si interactif.
- [ ] Sources et limites clairement signalées.
- [ ] Index et catalogue mis à jour.
- [ ] Aucun secret ou donnée personnelle dans le contenu.

## Pour un exemple de code
- [ ] L'environnement et les versions nécessaires sont précisés.
- [ ] Le code est complet ou explicitement marqué comme fragment/pseudocode.
- [ ] Le résultat attendu est indiqué.
- [ ] Les cas limites et erreurs importants sont abordés.
- [ ] Les tests sont exécutés, ou leur absence est explicitement signalée.
- [ ] La solution n'introduit pas de pratique dangereuse sans contexte de laboratoire.

## Pour un cours avancé
- [ ] Présentation HTML vérifiée au clavier et sur une fenêtre étroite.
- [ ] Objectifs observables, prérequis et durée réaliste documentés.
- [ ] Exemples exécutables et instructions de lancement présents.
- [ ] Au moins un laboratoire guidé avec critères d'acceptation.
- [ ] Exercices indépendants et starters présents.
- [ ] Solutions séparées des starters.
- [ ] Quiz avec réponses expliquées.
- [ ] Grille d'évaluation publiée.
- [ ] Catalogue cohérent avec les fichiers présents.
- [ ] Contrôles CI réussis.

## Statuts du catalogue
- **planned** : module planifié, support non livré.
- **presentation** : présentation disponible ; ressources d'enseignement encore incomplètes.
- **course** : contenu de cours et pratique disponibles, évaluation ou éléments de finition encore incomplets.
- **complete** : tous les critères applicables ci-dessus sont satisfaits et les contrôles ont été consultés.

Le statut est un signal de maturité, pas un élément marketing. Ne pas l'avancer pour refléter une intention.
