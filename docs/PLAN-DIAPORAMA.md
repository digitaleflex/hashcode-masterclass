## Principes de présentation

- Une idée principale par diapositive.
- Grandes tailles de texte pour une projection à distance.
- Peu de paragraphes ; privilégier schémas, comparaisons et extraits de code courts.
- Afficher le code progressivement lorsque cela facilite l'explication.
- Distinguer visuellement le code source et sa sortie attendue.
- Éviter les captures d'écran illisibles et les visuels décoratifs sans valeur pédagogique.
- Réserver les détails complémentaires aux notes du formateur.

## Exactitude technique

- TypeScript ajoute un système de types statiques à JavaScript ; il ne remplace pas le runtime JavaScript.
- Les annotations de types sont vérifiées lors du contrôle statique et ne constituent pas une validation automatique des données à l'exécution.
- Node.js est un environnement d'exécution JavaScript, tandis que npm gère les paquets et les scripts du projet.
- Vite est un outil de développement et de build ; React est une bibliothèque UI ; Next.js est un framework fondé sur React.
- Les démonstrations doivent être exécutées et validées avant la session.
