MODULE 01 · JAVASCRIPT · PARTIE 01

Contexte d’exécution

  • Le moteur exécute le code ; l’environnement fournit les API.
  • La Call Stack suit les appels actifs.
  • Le code synchrone s’exécute avant le traitement des microtâches.
  • Navigateur et Node.js ont des détails d’ordonnancement différents.
À retenir / mise en pratique
Un agent JavaScript exécute une tâche à la fois ; l’environnement orchestre l’asynchronisme.
MODULE 01 · JAVASCRIPT · PARTIE 02

Closures et portée

  • La portée lexicale dépend de l’endroit où une fonction est définie.
  • Une closure conserve l’accès à son environnement lexical.
  • Utile pour encapsuler un état et configurer des callbacks.
  • Une référence conservée trop longtemps peut retenir de la mémoire.
À retenir / mise en pratique
Exemple : const counter = () => { let n=0; return () => ++n; };
MODULE 01 · JAVASCRIPT · PARTIE 03

Event Loop

  • Le code courant s’exécute d’abord.
  • Les callbacks Promise et les reprises de await utilisent les microtâches.
  • setTimeout planifie une tâche ; son délai n’est pas une heure exacte.
  • Prédire l’ordre puis vérifier avec console.log.
À retenir / mise en pratique
Exercice : combiner un log direct, Promise.resolve().then(...) et setTimeout(...,0).
MODULE 01 · JAVASCRIPT · PARTIE 04

Prototypes et itération

  • Les objets délèguent la recherche de propriétés à leur prototype.
  • class s’appuie sur le système de prototypes.
  • Symbol.iterator définit le protocole itérable.
  • function* et yield produisent des valeurs à la demande.
À retenir / mise en pratique
Privilégier la composition lorsque l’héritage rend les relations trop complexes.
MODULE 01 · JAVASCRIPT · PARTIE 05

Asynchronisme robuste

  • Promise.all échoue dès qu’une promesse rejette.
  • Promise.allSettled recueille tous les résultats.
  • AbortController annule certaines opérations comme fetch.
  • Définir les comportements d’erreur, délai et annulation.
À retenir / mise en pratique
Limiter la concurrence au lieu de lancer un nombre illimité de requêtes.
MODULE 01 · JAVASCRIPT · PARTIE 06

Mémoire et atelier

  • Listeners non retirés, timers persistants et caches non bornés retiennent des objets.
  • Comparer des snapshots mémoire pour trouver les références conservées.
  • Écrire une closure, prédire un ordre d’exécution et créer un générateur.
  • Retirer un listener et démontrer la correction.
À retenir / mise en pratique
Maîtrise : expliquer le mécanisme, démontrer le comportement et tester les limites.
