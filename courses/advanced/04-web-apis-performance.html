MODULE 04 · WEB PLATFORM · PARTIE 01

Fetch et annulation

  • fetch ne rejette pas automatiquement sur HTTP 404 ou 500 : vérifier response.ok.
  • AbortController permet d’annuler certaines requêtes.
  • Prévoir loading, success, empty et error.
  • Éviter qu’une réponse ancienne écrase un résultat plus récent.
À retenir / mise en pratique
Exercice : recherche avec annulation de la requête précédente.
MODULE 04 · WEB PLATFORM · PARTIE 02

Stockage navigateur

  • LocalStorage est synchrone et adapté à de petites préférences.
  • IndexedDB convient à des données structurées plus volumineuses.
  • Le stockage peut être limité ou indisponible.
  • Ne pas y placer de secrets sensibles accessibles au JavaScript.
À retenir / mise en pratique
Prévoir un comportement de repli si le stockage échoue.
MODULE 04 · WEB PLATFORM · PARTIE 03

Web Workers

  • Un Worker exécute du code hors du thread principal.
  • Les messages définissent les échanges avec l’interface.
  • Un Worker n’accède pas directement au DOM.
  • Mesurer les coûts de transfert des données.
À retenir / mise en pratique
Utiliser les Workers pour du calcul coûteux, pas pour toute logique.
MODULE 04 · WEB PLATFORM · PARTIE 04

Performance

  • Profiler avant d’optimiser.
  • Identifier les longues tâches et fonctions coûteuses.
  • Réduire les ressources inutiles et le travail du thread principal.
  • Utiliser les Core Web Vitals comme indicateurs centrés sur l’expérience.
À retenir / mise en pratique
Comparer les mesures avant et après la correction.
MODULE 04 · WEB PLATFORM · PARTIE 05

Accessibilité et sécurité UI

  • Tout parcours doit fonctionner au clavier.
  • Les champs doivent avoir des labels et les erreurs être annoncées clairement.
  • Respecter focus visible et réduction des animations.
  • Éviter innerHTML avec du contenu non fiable.
À retenir / mise en pratique
Atelier : auditer un formulaire au clavier puis corriger ses défauts.
MODULE 04 · WEB PLATFORM · PARTIE 06

Évaluation

  • Gérer les états réseau et l’annulation.
  • Auditer labels, focus et navigation clavier.
  • Profiler une interaction lente.
  • Documenter les résultats mesurés.
À retenir / mise en pratique
Maîtrise : interface accessible, robuste et amélioration démontrée.
