# Grille d'évaluation — Backend Node.js et API

| Critère | Points | Attendu |
|---|---:|---|
| Contrat HTTP | 15 | Méthodes, statuts et erreurs cohérents |
| Architecture | 15 | Transport, domaine et infrastructure séparés à bon escient |
| Validation | 20 | Entrées, tailles et règles métier contrôlées |
| Autorisation | 20 | Permissions côté serveur sur chaque ressource |
| Tests d'intégration | 15 | Succès, erreurs, limites et accès refusés |
| Observabilité/sécurité | 15 | Logs expurgés, erreurs non révélatrices, SQL paramétré |

Réussite : 70/100. Accès non autorisé ou injection exploitable = défaut critique.
