# Cours avancés — HashCode Academy

Sept présentations HTML autonomes en français, avec navigation clavier, progression, affichage responsive et prise en compte de `prefers-reduced-motion`.

## Présentations
- [JavaScript avancé](01-javascript-avance.html)
- [TypeScript avancé](02-typescript-avance.html)
- [Tests avancés et qualité logicielle](03-tests-qualite.html)
- [Navigateur, Web APIs et performance](04-web-apis-performance.html)
- [Backend Node.js et API](05-node-backend-api.html)
- [Sécurité applicative approfondie](06-securite-applicative.html)
- [Architecture, DevOps et production](07-architecture-devops.html)

## Utilisation
Ouvrir un fichier HTML dans un navigateur moderne. Aucun serveur ni accès Internet n'est requis.

## État pédagogique
Cette première version est un support de présentation. Pour constituer un cours complet prêt à enseigner, chaque module devra être enrichi de démonstrations exécutables, laboratoires guidés, exercices corrigés, quiz et grille d'évaluation.
