# Exercices — Sécurité applicative

## INIT
Classer des scénarios en validation, encodage, authentification, autorisation, gestion de session ou journalisation.

## CORE
Auditer une page locale affichant une valeur utilisateur, corriger le sink DOM, ajouter un test et documenter le risque résiduel.

## PRO
Écrire un threat model pour une API de tâches : actifs, entrées, frontières de confiance, menaces, contrôles préventifs et risques résiduels.

## Revue
Auditer des logs fictifs et repérer jetons, mots de passe ou données personnelles à expurger.
