# Sécurité applicative

> HashCode Academy · Niveau intermédiaire · Durée indicative : 4–5 h

## Objectifs observables
À la fin du module, l'apprenant peut expliquer les concepts essentiels, construire une solution locale, tester les erreurs et cas limites et justifier les décisions techniques.

## Prérequis
Fondamentaux JavaScript, modules, fonctions et bases HTTP. Utiliser Node.js 20+ pour les ateliers Node et les tests ; navigateur moderne pour les exercices Web.

## Concepts essentiels
Modèle de menace, injection, XSS, sessions, autorisation, secrets et non-régression.

## Parcours proposé
1. Comprendre le modèle mental et les termes.
2. Exécuter les exemples et prédire le résultat avant de lancer.
3. Réaliser le laboratoire guidé.
4. Faire les exercices INIT, CORE puis PRO sans lire d'abord le corrigé.
5. Passer le quiz et s'autoévaluer avec la grille.

## Laboratoire central
Corriger une interface HTML locale qui affiche du texte utilisateur et rédiger un rapport de risque.

## Limites et précautions
Exclusivement systèmes locaux et autorisés ; aucun secret réel ni test de tiers.

## Erreurs fréquentes
- Tester seulement le chemin nominal.
- Confondre une démonstration pédagogique et une solution de production.
- Ajouter une dépendance sans justification.
- Affirmer qu'un test passe sans l'avoir exécuté.
- Oublier les cas limites, l'accessibilité ou la sécurité du domaine.

## Livrables
- Code ou prototype reproductible.
- Tests couvrant succès, erreurs et frontières.
- README avec versions, commandes et résultats attendus.
- Note courte sur décisions, alternatives et risques résiduels.

## Critères de maîtrise
L'apprenant peut expliquer le concept, refaire l'exemple sans copier, traiter un cas limite, exécuter les tests et décrire ce que les tests ne garantissent pas.
