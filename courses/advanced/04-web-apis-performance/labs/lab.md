# Laboratoire guidé — Web APIs et performance

**Durée :** 60 minutes · Navigateur moderne · Données locales

## Mission
Construire une recherche locale avec états chargement/vide/erreur, gestion des requêtes obsolètes, labels et focus visible.

## Étapes
1. Créer un jeu de données local.
2. Afficher chargement, résultats, état vide et erreur.
3. Annuler ou ignorer les requêtes obsolètes.
4. Gérer JSON invalide et stockage indisponible.
5. Ajouter labels, focus visible et annonce accessible du statut.
6. Mesurer le filtrage de 5 000 éléments avant d'optimiser.

## Critères
- [ ] Les réponses obsolètes ne remplacent pas les plus récentes.
- [ ] Les erreurs ont un message compréhensible.
- [ ] Le parcours fonctionne au clavier.
- [ ] Le focus est visible.
- [ ] Les mesures sont reproductibles.
- [ ] Aucun service public n'est requis.
